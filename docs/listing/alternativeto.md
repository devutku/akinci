## Short description (kısa açıklama)

> Free, open-source download manager that splits files into up to 32 parallel connections, resumes interrupted downloads and checks finished files with VirusTotal.

## Description (açıklama)

> Akıncı is a free and open-source download manager built with .NET 10 and Avalonia (Turkish interface).
>
> - **Multi-connection downloads:** splits files into up to 32 parallel parts; connections that finish early take over the remaining work of slower parts.
> - **Resume:** retries dropped connections automatically and pauses/saves downloads when the app closes, so they continue where they left off.
> - **VirusTotal scan:** when a download finishes, its SHA-256 hash is looked up against 70+ antivirus engines (the file itself is never uploaded).
> - **Browser integration:** a Chrome/Edge extension (Chrome Web Store) hands downloads over to Akıncı, adds "Download with Akıncı" to the context menu and detects HLS/DASH video streams.
> - **Speed limit & queue:** global bandwidth limit and a configurable number of simultaneous downloads.
> - **Protocols & auth:** HTTP/HTTPS, FTP/FTPS, HLS; Basic, NTLM, Kerberos and Negotiate authentication; works with sites you are signed in to.
> - Per-user installer (no admin rights), uninstall from Control Panel, no ads, no telemetry.
