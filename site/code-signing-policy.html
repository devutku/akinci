Code signing policy

Kod imzalama politikası

Code signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows binaries of Akıncı (Akinci.exe, Akinci-CLI.exe, Akinci-BrowserBridge.exe) and the installer (Akinci-Setup-<version>.exe) are built by GitHub Actions from the public source code at github.com/devutku/akinci and are signed through SignPath. Every signing request is approved manually by a project approver.

Status: the application for a SignPath Foundation certificate is in progress. Releases published before code signing is active are not signed.

Akıncı'nın Windows dosyaları ve kurulum programı, herkese açık kaynak kodundan GitHub Actions ile derlenir ve SignPath üzerinden imzalanır; her imzalama isteği proje onaylayıcısı tarafından elle onaylanır. Durum: SignPath Foundation sertifikası başvurusu sürüyor; imzalama etkinleşmeden önce yayınlanan sürümler imzasızdır.

Team roles

  • Committers and reviewers: devutku
  • Approvers: devutku

Ekip rolleri: Kod yazma, inceleme ve imzalama onayı rolleri proje sahibi devutku tarafından yürütülür. Proje dışından gelen her değişiklik (pull request) birleştirilmeden önce incelenir.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Downloads are made only from addresses the user requests; the optional VirusTotal check sends only the SHA-256 hash of a finished file and only if the user enters a VirusTotal API key; the browser extension sends download details only to the Akıncı app on the same computer.

Full privacy policy: PRIVACY.md

Bu program, kullanıcı ya da onu kuran/çalıştıran kişi açıkça istemedikçe hiçbir bilgiyi başka ağ sistemlerine aktarmaz. Ayrıntılar: Gizlilik politikası.
